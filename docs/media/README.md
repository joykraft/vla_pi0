# Demo media / 实机展示素材

素材来自项目作者提供的实机录像。封面直接取自原视频帧；动作片段保持连续时序，没有合成机器人动作。

Media comes from the project author's real-robot recording. The cover is an extracted source frame; the demonstration is a continuous excerpt with no synthesized robot actions.

Original recordings remain local. The repository contains a cover, a GIF, and a compressed excerpt suitable for web display. Both README languages share these files, which can also be reused on a future portfolio page.
